# 実際のフォルダー表示（Thunderbird / Betterbird アドオン）

統合フォルダー（Unified Folders / スマートフォルダー）などでメールを開いたとき、
そのメールが実際にはどのアカウントのどのフォルダーに保存されているかを、
**メール本文の一番上（件名・差出人のすぐ下）にバナーとして常時テキスト表示**します。

## 表示内容

- **本文先頭のバナー**: 「実際のフォルダー: アカウント名 / フォルダー名」
  - **統合フォルダーなど、実フォルダーとは別の場所から見ている時だけ表示されます。**
  - 実フォルダーそのものを直接開いている場合（統合フォルダーを経由していない場合）は、
    表示する意味がないため自動的に非表示になります。
- ツールバーへのボタン追加はありません（バナー表示のみのシンプルな構成です）。

## 導入手順

1. このフォルダ一式（`manifest.json`, `background.js`, `content/`, `icons/`）を
   ZIPにまとめ、拡張子を `.xpi` にする（`thunderbird-real-folder.xpi` として同梱済み）
2. メニュー →「アドオンとテーマ」を開く
3. 歯車アイコン →「ファイルからアドオンをインストール」
4. `.xpi` ファイルを選択する
   - 開発中に手軽に試したい場合は `about:debugging` →
     「このThunderbird」→「一時的なアドオンを読み込む」から
     `manifest.json` を直接選択する方法もあります

## 動作条件・注意点

- Thunderbird 102以降（Betterbirdでも同様のWebExtension APIがそのまま使えます）
- **バナーは「インストール／有効化した後に新しく開いたメール」から表示されます。**
  既に開いているメールタブでは表示されないことがあるので、
  一度別のメールに切り替える、またはThunderbirdを再起動してください。
- バナーはメール本文の表示領域内に挿入されるため、メールごとのレイアウトや
  横幅の狭いプレビューペインでは折り返して表示されることがあります。

## 技術的な補足

- Thunderbirdの「差出人・件名」が表示されるネイティブのヘッダー部分自体は、
  標準のWebExtension APIからは書き換えられません。そのため、その直下にあたる
  「メール本文の先頭」にバナーを差し込むことで、視覚的に近い位置への
  常時表示を実現しています。
- 「統合フォルダー経由かどうか」の判定には `mailTabs` APIで取得した
  現在表示中のフォルダー情報と、メールの実フォルダーを比較しています。
  別ウィンドウ・別タブでメールを単独で開いた場合など、判定できないケースは
  安全側（表示する）に倒しています。
